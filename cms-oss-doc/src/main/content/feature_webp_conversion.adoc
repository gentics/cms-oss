= Automatic WEBP Conversion

Uploaded images are automatically converted to the WEBP format. The “Convert Images” scheduler task converts existing images in nodes that have this feature enabled.

[#feature-activation]
== Feature activation

If you want to use this feature, you first have to enable it

.conf/features.yml
[source,javascript]
----
feature:
    webp_conversion: true
----
