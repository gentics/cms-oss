h2. Activation Process

Licensed Features listed in the "Gentics CMS Feature Overview":ee-feature_overview.html must be activated.
First the feature needs to be added to the license key. This can be done by sending a license activation request to __license@gentics.com__.
After the license request has been granted, the activation of the CMS must be updated. The exact workflow for doing this depends on whether auto-activation is possible or not.

endprologue.

h3. Auto-activation

When the CMS server can access the activation service (under https://secure.gentics.com/service/activation/), it is possible to use auto-activation.

In order to trigger auto-activation, remove the activation information from the keyfile.

* license.key:
<shell>
1234-5678-9123-4567-8912-3456-7890-1234
6314E8EE755209DD58ADB65A018DD81C
302C02141FC3E44CEE28EEE83EABBAFF376BC77E1CE02C5C02147E773456A1F93F1B3C4A09C928E96C1EAF4EFC89
CN
</shell>

* Change to:
<shell>
1234-5678-9123-4567-8912-3456-7890-1234
</shell>

After this step the CMS Server needs to be restarted. The restart will automatically invoke a reactivation of the license key. After the activation has been completed the license key file should look similar to this:

<shell>
1234-5678-9123-4567-8912-3456-7890-1234
6314E8EE755209DD58ADB65A018DD81C
302C02141FC3E44CEE28EEE83EABBAFF376BC77E1CE02C5C02147E773456A1F93F1B3C4A09C928E96C1EAF4EFC89
CN,TTM,MCCR
</shell>

The last line of the license key should now contain the licensed feature information.

h3. Manual Activation

If the CMS server cannot access the activation service, the activation can be done manually with the following steps:

# Access https://secure.gentics.com/service/activation/?product=CN&version=[CMS Version] with a web browser. [CMS Version] must be your currently used CMS Version (e.g. 6.0.18).
# Enter your license key and click on "Aktivierung durchführen"
# A download of the activated license.key file will be triggered.
# Place the license.key file on your CMS server (replacing the existing one).
# Restart the CMS
